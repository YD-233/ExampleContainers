## 设计综述

### 1. 选题背景与意义

随着企业网络环境日益复杂，渗透测试工作对远程控制系统的跨平台支持、模块化设计和可扩展能力提出了更高要求。传统远控工具往往存在架构耦合度高、扩展困难、功能集成不灵活等问题，而 Mythic 作为面向渗透测试与红队演练的容器化框架，能够为 Agent 与通信组件的定制开发提供较为清晰的扩展接口。

本课题的研究意义主要体现在两个方面：一方面，通过在 Mythic 框架下开发自定义 Agent 与通信配置逻辑，可以系统性地理解现代 C2 系统的任务流转、通信封装和模块组织方式；另一方面，通过实现命令执行、文件管理、SOCKS5 代理、系统状态收集和辅助提权模块，可以搭建一套适用于受控实验环境的远控系统原型，为后续开展渗透测试技术研究和对抗分析提供实验基础。

### 2. 国内外相关发展现状与趋势

国际上，Cobalt Strike、Mythic、Sliver 等现代 C2 框架已经普遍采用模块化设计思路，将通信层、任务处理层和功能模块解耦，以便适配不同操作系统和不同通信场景。其中，Go 语言因其跨平台编译能力、并发模型和网络编程优势，被广泛用于 Agent 开发。

国内相关研究更多聚焦于网络攻防平台、加密流量通信、内网代理转发和权限维持等方向。在工程实现上，许多研究与产品开始强调“可扩展而非大而全”的设计理念，即在稳定的主框架上逐步叠加命令执行、文件传输、信息收集和代理模块。本课题将结合这一发展趋势，围绕 Mythic 框架实现一个以实验验证为目标的远控系统原型。

### 3. 设计目标及主要内容

本课题拟基于 Mythic 框架完成一个面向实验环境的渗透测试远控系统设计与实现，主要目标如下：

1. 设计并实现基于 HTTP/HTTPS 的 Beaconing 通信机制，完成 Agent 与 Mythic 的任务轮询和结果回传。
2. 使用 Go 语言开发跨平台 Agent，支持命令执行、文件上传下载、目录管理和系统状态收集。
3. 实现简单的 SOCKS5 代理功能，支持基础账号密码认证，用于实验环境下的流量转发验证。
4. 设计信息收集模块，实现对系统、网络、用户、进程等信息的基础采集。
5. 设计辅助提权模块，不自行编写复杂提权利用代码，而是支持调用开源提权辅助工具或执行提权环境探测，以形成实验环境中的提权分析能力。
6. 在通信层提供基础伪装能力，包括可配置的 Host、User-Agent、请求头、请求路径以及心跳间隔抖动等，以提升系统的可配置性与实验表现。

### 4. 总体方案

本系统采用“基于 Mythic 扩展的 C/S 架构”进行设计，主要由 Mythic 控制端、通信配置层和 Agent 执行端三部分组成。

1. 控制端方案：复用 Mythic 提供的任务管理、消息分发和结果展示能力，将自定义 Agent 以 Payload Type 的形式接入框架，实现任务生命周期管理。
2. 通信方案：以 HTTP/HTTPS 为主要通信载体，采用 Beaconing 模式定时轮询服务端。通信请求支持基础加密封装、Header 伪装、Host 伪装、User-Agent 伪装和路径可配置。
3. Agent 方案：Agent 采用 Go 语言开发，内部按模块划分为通信模块、命令执行模块、文件管理模块、SOCKS5 代理模块、系统状态收集模块、信息收集模块和辅助提权模块。
4. 测试方案：搭建由 Mythic、Windows 靶机和 Linux 靶机构成的虚拟测试环境，围绕命令执行、文件传输、代理转发、信息收集和通信稳定性进行功能验证。

## 设计思路、实现方法以及手段

### 1. 设计思路

本设计遵循“先实现核心链路，再扩展功能模块”的思路。首先完成 Agent 的基础通信、任务轮询和结果回传，确保系统具备最小可运行能力；然后逐步实现命令执行、文件管理、SOCKS5 代理、系统状态收集和信息收集；最后再补充辅助提权模块和基础通信伪装能力，使系统形成完整的毕业设计原型。

在模块组织上，系统强调高内聚、低耦合。Agent 内部各模块通过统一的任务分发机制进行调用，通信层负责处理与 Mythic 的对接，功能模块负责处理各自的业务逻辑。这样既便于后续功能扩展，也利于论文中对系统架构和模块关系进行分析说明。

### 2. 实现方法及手段

1. 开发与部署环境：服务端依托 Docker 部署 Mythic 主服务，Agent 与相关扩展模块使用 Go 语言开发。
2. 通信实现：通过 HTTP/HTTPS 请求实现 Beaconing 轮询，使用 JSON 格式封装任务与响应数据，并结合基础加密方式完成消息保护。
3. 伪装实现：通过配置 User-Agent、Host、请求路径和其他常见请求头，实现对正常 Web 请求特征的基础模拟；同时支持心跳间隔抖动，降低通信行为的固定性。
4. 功能实现：
   - 命令执行模块基于系统命令调用实现标准输出和错误输出采集。
   - 文件管理模块实现目录浏览、文件上传和文件下载。
   - SOCKS5 代理模块实现基础 CONNECT 转发，并支持账号密码认证。
   - 系统状态收集与信息收集模块实现对主机信息、网络信息、用户信息、进程信息等的基础采集。
   - 辅助提权模块通过调用开源提权辅助工具或执行环境探测脚本，输出潜在提权路径与检测结果。
5. 测试手段：使用虚拟机搭建实验环境，通过功能测试、长时间运行测试和抓包分析验证系统的稳定性、跨平台性和通信表现。
